# OSR標高管理 Pro v9 (PWA)

施工用基準レベル標高値(O.P.)を現場のスマートフォンで簡単に管理・入力するためのウェブアプリケーションです。
ブラウザ上で動作し、PWA（Progressive Web App）としてホーム画面に追加することで、ネイティブアプリのように全画面で利用可能です。

## 主な機能
- **測点の階層管理**: 1級基準点(測量シール)、2級基準点(水準点・KBM)、3級基準点(構台・アングル等)の3タブ構成で管理
- **水準点・測量シールの管理**: 初期値、前月値、当月値の記録と変位差の自動計算
- **測点データ**: 2026/8/26（第3回計測）時点の値（1級4点・KBM・2級⑤〜⑩・3級⑪〜⑯）。「📍 配置図」で場内 測点配置図を表示
- **テンキー入力**: スマホでの屋外作業に最適化された専用テンキーパッド
- **PWA対応（オフライン対応）**: 現場の電波が悪い場所でもサクサク動作
- **PDF帳票出力**: 現場で入力したデータをその場でA4横サイズのPDF（3カラム出力）として出力可能
- **CSVデータ出力**: Excelなどでの二次利用のためにデータをCSVエクスポート
- **バックアップ・復元**: アプリ内のデータをJSONファイルとして一括保存し、機種変更時などに簡単に引き継ぎ可能
- **ダークモード対応**: 屋内の暗い環境でも見やすいテーマ切り替え

## 水辺変状計測（別ページ: `henjo.html`）
標高管理とは別に、OSRプロジェクト水辺工事に伴う変状計測（X・Y・Z）を管理するページです。標高管理画面の「📐 変状計測」ボタンから開きます。データは標高管理とは別に保存されます。
原本 `20261024_OSR水辺変状計測.xlsx` の計算式・判定・様式を移植しています。

- **測点**: 計測用BM 2点（BM-1・BM-2）＋水辺変状計測点16点（ML1-1〜ML8-2）＝提出18点、補助計測点8点（ML1-3〜ML8-3・社内管理のみ）。初期値は2026/10/23計測（基準座標図2026.10.24と照合）
- **計測回**: 第1回〜第36回（月1回で約3年分）
- **取込**: SIMA（A01行）・CSV・タブ区切りを自動判別。判定（OK / OK・差大 / 点名なし / 重複 / 数値エラー / XY入替? / 対象外行）と本番照合（反映済 / 本番で修正）はExcelと同じ。SIMAファイル（Shift_JIS）も直接読込可
- **管理表**: 初期値との差・前回との差（mm、四捨五入）と変位方向。注意値以上＝黄、管理値以上＝赤（初期値 XY 10/15mm、Z 5/10mm、「基準」タブで変更）。カードをタップして直接打ち換え可
- **A3出力**: 表示開始回（最新／1〜31）から6回分の測点変位管理表＋経年変化グラフ16点＋配置図（全体図）のA3横3枚（配置図はチェックで添付の有無を切替）。印刷またはPDF保存
- **配置図**: 水辺変状計測基準座標図（全体図・拡大図4面、拡大表示可、原本PDFを開く）と測点の場所一覧
- **データ**: バックアップ（JSON）・復元、全回CSV出力、回ごとのSIMA出力（Excelの「計測値取込」へ貼付可）
- 計算コアは `henjo-core.js`、テストは `node test/henjo-core.test.js`

## 使い方（インストール方法）
**公開URL:** [https://hyoko-survey-app.vercel.app/](https://hyoko-survey-app.vercel.app/)

1. スマホのブラウザ（iOSはSafari、AndroidはChrome推奨）で上記の公開URLにアクセスします。
2. ブラウザのメニューから「ホーム画面に追加」をタップします。
3. ホーム画面に追加されたアイコンからアプリを起動して使用します。
